Cara Menghubungkan WhatsApp

1

Buka WhatsApp di Ponsel Anda

Pastikan ponsel terhubung ke internet dan buka aplikasi WhatsApp.

2

Buka Menu Perangkat Tertaut

Ketuk ikon Titik Tiga (Android) atau Pengaturan (iOS) > pilih Perangkat Tertaut.

3

Tautkan Perangkat

Ketuk tombol Tautkan Perangkat lalu arahkan kamera ponsel ke QR Code di sebelah kiri.

4

Bot Siap Melayani

Setelah scan berhasil, chatbot langsung aktif otomatis melayani pelanggan 24/7!

Multi-Device: Sesi disimpan otomatis di folder lokal. Anda tidak perlu scan ulang setiap kali aplikasi dijalankan kembali.
